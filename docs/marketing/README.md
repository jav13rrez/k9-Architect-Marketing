## Reglas de mantenimiento

1. Toda pieza de producto se contrasta con [`RELEASE-READINESS-AND-CLAIMS.md`](../product/RELEASE-READINESS-AND-CLAIMS.md).
2. B2B y B2C usan campañas, UTMs, audiencias, landings y paneles separados.
3. Un hallazgo puede alimentar ambas líneas, pero el copy se reescribe para cada audiencia.
4. No publicar precios hasta validar catálogo live, moneda, impuestos y condiciones.
5. No usar casos reales, testimonios o datos de tracción sin evidencia y permiso.
6. Actualizar primero investigación/claims; después estrategia, campaña y landing afectadas.
